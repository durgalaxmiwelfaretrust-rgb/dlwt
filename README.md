# Durgalaxmi Welfare Trust — Multi-page website

This is a multi-page static website for GitHub Pages. The homepage is `index.html`; each section has its own HTML page and URL.

## Included pages
- Home (`index.html`)
- About Us (`about.html`)
- Our Team (`team.html`)
- Initiatives (`initiatives.html`)
- Gallery (`gallery.html`)
- DLWT Society of Scholars (`scholars.html`)
- News & Activities (`news.html`)
- Annual Reports (`reports.html`)
- Donate (`donate.html`)
- Contact Us (`contact.html`)

## Upload to GitHub
1. Extract this ZIP file.
2. Open the extracted `DLWT_Multipage_Website` folder.
3. Select everything inside it (including `index.html`, the other `.html` pages, `README.md`, and `assets`).
4. In your existing repository `durgalaxmiwelfaretrust-rgb/dlwt`, choose **Add file → Upload files**.
5. Drag the selected contents into GitHub. Do not upload the outer folder itself.
6. Commit the changes to the `main` branch.
7. Open **Settings → Pages**. Set Source to **Deploy from a branch**, Branch to **main**, folder to **/(root)**, then Save.

## Add your project photographs
Put approved images into `assets/gallery/`. Send the photographs and tell us which initiative each group belongs to; the gallery page can then be updated with image cards, captions and categories.

## Add annual reports
Put approved PDFs into `assets/documents/`, then add their filenames and titles to `reports.html`.

## Important checks before public launch
- Verify bank account, IFSC, UPI QR, phone, email, address and statutory registration details.
- Confirm the current validity and public-use wording for 80G and 12A details.
- Add approved trustee names, designations and photographs on `team.html`.
- Add only photographs for which the Trust has permission to publish, especially images of children.
- The contact page currently uses an email link rather than a backend form; GitHub Pages hosts static websites and does not process form submissions by itself.

## Domain
After testing the GitHub Pages website, a custom domain can be connected under **Settings → Pages → Custom domain**. Domain purchase and DNS configuration are separate from the website design.
