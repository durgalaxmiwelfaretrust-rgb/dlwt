# Durgalaxmi Welfare Trust — GitHub Pages website

This is a responsive, one-page static website for Durgalaxmi Welfare Trust (DLWT) and the DLWT Society of Scholars.

## Files
- `index.html` — website content
- `style.css` — responsive styling
- `assets/donation-qr.png` — QR image supplied for this website

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `dlwt-website`.
2. Upload all files and folders from this package. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will provide the website URL, usually `https://YOUR-USERNAME.github.io/dlwt-website/`.

For a user/organization site at `https://YOUR-USERNAME.github.io/`, name the repository `YOUR-USERNAME.github.io`.

## Before publishing
- Scan-test the supplied QR code using at least two UPI apps and confirm the recipient name and VPA. The supplied image is included unchanged.
- Verify the bank details, legal registration numbers, contact information, and membership benefit wording against current Trust records.
- The website displays the bank and registration details exactly as provided. Consider that these details will be publicly visible on a public GitHub Pages site.
- Add the Trust's official logo and real project photographs if available.
- This package does not publish to your GitHub account automatically; upload the files using the steps above.
